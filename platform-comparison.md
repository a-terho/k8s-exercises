For a small developer Rancher is probably easier to get into.

Rancher

- Centralized access control, security policy and authentication
- Centralized observability, backups, logs auditing and upgrades
- Multi-cloud support allowing centralized deployment for heterogenous clusters
- Seamless integration with popular tools like Prometheus, Grafana and Istio
- Customizability with extensions and integrations library provided by Rancher
- Apparently cheaper out of the two, even has free community version

Red Hat OpenShift

- Single consistent platform on which to deploy and scale applications
- Runs mainly on Red Hat Enterprise Linux (RHEL) on nodes
- Integrated support for CI/CD pipelines, monitoring and automated maintenance
- More security and compliance features out-of-the-box
- Bundles with web console and CLI for developers and IT operators
- Acts more as "all-in-one" platform, requires learning Red Hat conventions
- Is pricier and has bigger market position compared to Rancher
